# 渲染问题定位

目标：把"感觉不对"收敛成"某个 pass 的某一行在某条件下算错"，每一步都有证据。

## 0. 先建立可复现基线

- 固定 `rendererInfo.xml`（渲染器、分辨率、场景、参数）并记录下来。
- 跑一次，保存日志（`_bin/Release/log_FzbRenderer_nvvk.txt`）和截图。
- 没有基线的"修复"，无法证明有效。

## 1. 先排除假因（本仓库最常见的四种）

1. **陈旧 shader 缓存**：`.spv` 比 `.slang` 新就直接用缓存。改了 shader 先删同名 `.spv`。
2. **shader 编译失败但静默**：画面上看不出来，必须搜日志里的 `[SlangCompile]`、`Error compiling`。
3. **配置没生效**：xml 改了但 exe 找不到源目录（`TARGET_EXE_TO_SOURCE_DIRECTORY`），或 xml 里的 `type` 不是你以为的那个渲染器。
4. **在改未提交代码**：没有 git 基线时，"改回去"这事不可靠。

## 2. 二分定位（一次只改一个变量）

按代价从低到高：

1. **开关**：用 xml 参数关掉可疑特性（NEE、path guiding、某种采样），看现象是否消失。
2. **pass 隔离**：只跑到某个 pass，把中间 buffer 直接可视化。
3. **输入简化**：换更简单的场景、单光源、单材质。
4. **代码**：加临时 dump，或把可疑行替换成常量。

每步记录：**假设 → 实验 → 观察 → 结论（成立/不成立）**。不成立的假设也要记，避免绕圈。

## 3. 常见根因速查

- 偏暗/偏亮：能量守恒、pdf 与 MIS 权重、采样数归一化、tonemap 位置。
- 噪点/条纹：采样相关性、随机种子、时间累积帧没重置。
- 漏光/黑块：barrier 缺失、descriptor 未更新、BVH/八叉树包围盒算错。
- 闪烁：累积缓冲未清空、相机矩阵与抖动不一致。
- 崩溃：validation layer 消息优先于一切；Aftermath 默认关闭，需要时再开。
- 改了没效果：`.spv` 缓存、shader 编译失败、改错渲染器。

## 4. 收尾

- 给出：**最可能的根因 + 支撑证据 + 已排除的假设**。
- 如果只是"现象消失"但机理不明，明确写"未定位到根因"，不要包装成已解决。
